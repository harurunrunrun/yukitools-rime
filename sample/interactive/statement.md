# Guess the Secret

ジャッジが隠した整数 S（1 ≤ S ≤ 100）を、7回以内の質問で特定してください。
これはインタラクティブ問題です。

## 対話手順

1. 最初に上限 `100` が与えられます。Sそのものは与えられません。
2. `? X`（1 ≤ X ≤ 100）を出力すると、S < Xなら `LESS`、
   S > Xなら `GREATER`、S = Xなら `EQUAL` が返ります。
3. 答えが分かったら `! S` を出力します。正解なら `OK` が返り、終了してください。
   最終回答は質問回数に含めません。

出力ごとに改行し、必ずflushしてください。不正な形式・範囲外・質問回数超過・誤答には
`-1` が返ります。その場合も直ちに終了してください。
各出力行は改行を含め64文字以内とし、最終回答後の追加出力は禁止です。

## 対話例（S = 42）

| 解答の出力 | ジャッジからの入力 |
| --- | --- |
| （開始） | 100 |
| ? 50 | LESS |
| ? 42 | EQUAL |
| ! 42 | OK |
